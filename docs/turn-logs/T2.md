## Failures investigated and corrected

- Initial strict typing found a list inferred as tuples with a null-only section
  label. It now has an explicit optional-string tuple type.
- Strict typing found two overly broad redirect-handler parameter types. They
  now match the standard-library binary stream and HTTPMessage signatures.
- Initial formatting/lint errors were corrected before any commit or push.
- T1's global `corpus/` ignore hid the new source module. Runtime directory
  ignores and the file guard are now root-scoped, with a regression test and
  wheel inspection. Corpus artefacts remain forbidden in Git.
- A real English sample's 78-character underscore divider caused a false
  repeated-letter issue. The corrected rule checks alphabetic runs.
- Combining marks initially reduced readability scores. The denominator now
  excludes combining marks, with a Tamil regression case. Replacement-character
  failures in the actual Sinhala/Tamil samples remain quarantined.
- Early synthetic staging outputs from the in-progress schema were replaced
  only after checking their known synthetic identity. Real research artefacts
  and original bytes were preserved. Published T1 contracts were not changed.
